# Code of conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be direct about code, generous about people.
- No harassment, discrimination, or personal attacks. No sexualized language or
  imagery. No sustained disruption of discussion.
- Assume a reader's mistake is a mistake, not bad faith — until it is clearly
  not.
- Respect privacy: do not post another person's books, notes, account data,
  logs, or private correspondence.
- Do not use the issue tracker to discuss piracy, DRM circumvention, or
  unlicensed book distribution.

## Scope

Applies in all project spaces: repositories, issues, pull requests, discussions,
and any communication made in the project's name.

## Enforcement

Report a conduct problem privately to the maintainers through GitHub (a private
message to a repository maintainer, or a private security advisory when the
report is sensitive). Do not open a public issue naming individuals.

Maintainers will review, may remove content, and may warn, temporarily restrict,
or permanently ban a participant. Reports are handled confidentially; the
reporter's identity is not disclosed without consent unless legally required.
